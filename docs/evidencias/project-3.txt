## Intentional behavior changes
- `password` is no longer in the responses of POST /users, GET /users/<id>, PUT /users/<id> and /login (AP-05).
- The login `token` is now a signed token instead of `fake-jwt-token-<id>`.
- Debug now defaults to off (AP-01).
- DELETE /tasks, /users, /categories and PUT /users with `role` or `active` check `X-Admin-Token` (AP-04). If `ADMIN_TOKEN` isn't set, they still work outside production and log a warning. In production they return 403.
- Invalid types that used to cause 500 errors now return 400: string priority, non-numeric `priority` or `user_id` in /tasks/search, empty body on PUT /categories, non-boolean `active`, empty `name`.
